- 输出：
  - `D:\ai\work\千里眼DICT集成服务细化管理方案宣贯材料_可编辑版.pptx`
  - `D:\ai\work\千里眼DICT集成服务细化管理方案宣贯材料_保真参考版.pptx`
- 经验：中文路径在 Python 读取时可能触发编码问题，先复制到英文路径处理更稳；用 PyMuPDF 读取 PDF 文本坐标/矢量图形，用 python-pptx 生成 WPS 可编辑 PPTX；复杂 Logo/图片作为图片对象保留。
- 后续优化：用户偏好“高保真兜底背景 + 可编辑文字/图片/简单形状”的混合版。做法是每页先铺原 PDF 渲染图作为底图，再叠加可编辑文字、图片和简单形状；如中文文件名在 Python 中乱码，用 PowerShell 从英文中间文件复制为正确中文名。
- 纠偏：如果可见重建层导致“跟原本效果完全不一样”，不要再用可见遮罩/形状覆盖。改用“高保真底图 + 透明可编辑文字层”：视觉只由 PDF 渲染底图负责，文字层保留为可编辑但透明，避免双重渲染和错位。
- 最终本地转换器方案：`pdf_to_local_editable_pptx_converter.py`。输出文件为 `D:\ai\work\千里眼DICT集成服务细化管理方案宣贯材料_本地高保真可编辑版.pptx`。做法是可见 PDF 高清底图 + 透明可编辑文字/图片/简单形状层。验证方式是用 WPS 打开最终 PPTX 导出 PDF，与纯底图参考版导出的 PDF 做逐页像素对比；本次 9 页对比结果均为 `mean_diff=0`、`max_diff=0`。
- 重要坑：PyMuPDF 直接 `alpha=False` 渲染带透明背景的 PDF 可能在 PPT/WPS 中表现为黑底。正确做法是 `alpha=True` 得到 RGBA，再用 PIL 合成到白底后保存为 PNG。修复版文件：`D:\ai\work\千里眼DICT集成服务细化管理方案宣贯材料_本地高保真可编辑版_修复白底.pptx`。
- 最终纠偏：透明可编辑层不满足实际编辑要求；无遮罩叠字会文字变粗；矩形遮罩会出现白框。当前较优方案是：先对 PDF 文本行做 redaction，生成“去文字但保留背景/图形/Logo”的底图，再叠加真实可见可编辑文本框和简单矩形对象。最终文件：`D:\ai\work\千里眼DICT集成服务细化管理方案宣贯材料_最终可编辑版.pptx`，包含 9 页、336 个可编辑文本框、99 个矩形图形对象、9 张页面背景图。
