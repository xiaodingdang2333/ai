# 七猫投稿共享规则

更新时间：2026-06-03

触发方式：用户说“写小说在七猫投”“七猫投稿”“七猫内投”“按七猫过稿口味写”时，先参考本规则。

默认试投量：首次开一本七猫投稿/内投新书时，默认先写 2 万字以上试投稿，除非用户明确要求更短。

## 起因

`坏运气寄存处`被七猫拒稿，理由是“综合质量一般、整体内容比较普通且缺乏吸引力”。后续七猫试投稿不再只追求设定完整和文笔顺滑，而是优先解决“开篇吸引力、题材辨识度、爽点可见度”。

## 作家交流区三板斧

- 竖屏阅读优先：句号分段，避免大段压屏；段落短，但不要机械一行一句。
- 前100字要给好奇点，前300字要同时出现情绪、冲突、噱头。
- 背景、世界观、人物履历不要开头集中解释，只在行动中穿插，单次尽量不超过约50字。
- 开篇优先结构：主角遭遇危机 + 觉醒金手指或抓住反制资源 + 解决眼前危机 + 当场打脸 + 引起共鸣 + 章尾反转留下一轮危机。
- 写前先扫同类型排行榜前排作品，拆开篇节奏、冲突密度、金手指落点和章尾钩子，再做原创仿写，拒绝照搬。

## 七猫排行榜样本共性

参考本地 `F:\ai\txt\排行榜\七猫排行榜\` 下的前排样本，包括古言生子、现言豪门替嫁、通房宅斗、年代军婚/大院、玄学地府等。

共性如下：

- 标题即卖点：书名直接给出身份反差、关系张力或爽点承诺，如绝嗣生子、霍二爷新婚、通房破戒、带空间小萌宝、地府皇妃。
- 第一章不开“设定说明会”，而是从危机现场切入：拦轿认子、包厢偷听背叛、被选通房、冒雪抢身份、车祸诈尸/命案现场。
- 女主开局处境一定难看：被羞辱、被替代、被卖、被迫嫁、被误会、差点死；但不能一直挨打，必须很快拿出筹码反击。
- 爽点要物化：胎儿、证物、婚约/替嫁资格、空间规则、旧物/尸体/命案、公开场合的耳光或认亲，尽量让读者看得见。
- 金手指或核心筹码要早露面，但不要一次讲完规则；先用一次解决眼前问题，再逐章补规则。
- 男主或关键庇护者要早出场或早形成压力：权臣、霍二爷、世子、军区大院、三皇子等，给女主带来更高阶的冲突场。
- 每章要有“眼前局”：这一章具体要抢什么、证明什么、保住什么、打谁的脸，而不是只推进情绪。
- 章尾继续抛新问题：孩子身份能否坐实、替嫁后更大的婚局、主母考验、真正收养名额、尸案下一个死者。
- 七猫开篇更吃“强情绪 + 强钩子 + 明确类型承诺”，不是单纯靠文笔、氛围或大设定。

## 写作执行清单

写七猫投稿稿前先确认：

- 书名是否一眼看出类型和爽点？
- 前100字有没有能停住手指的好奇点？
- 前300字有没有情绪、冲突、噱头？
- 第一章是否已经让女主行动，而不是只解释？
- 女主是否在第一章内拿到或展示一个反制筹码？
- 第一章结尾是否有新危机或反转？
- 每章是否能用一句话说清“本章打脸/保命/抢资源/查证据”的目标？
