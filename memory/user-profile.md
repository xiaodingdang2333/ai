# User Profile

- Preferred language: Chinese, unless the user asks otherwise.
- The user values concise, direct help with low token usage.
- The user often wants Codex to perform the work locally instead of only explaining steps.
- The user works mainly on Windows, commonly under `F:\ai`.
- Novel prose preference update: template phrases are not absolutely forbidden, but should be sparse and natural rather than dense default prose.
- Novel chapter length preference: unless the user says otherwise, each formal chapter should be at least 2500 Chinese characters.
- For novel writing, the user wants non-formulaic female-oriented commercial fiction: avoid流水式对话 and one-sentence paragraphs, use more细腻描写, strong hooks, creative but not gimmicky premises, and names/plots that do not look like obvious copies of trending books.
