# 第一卷：南悬巷雨夜

## 卷功能

用旧宅整理切入，让读者先看见江照眠的职业能力和南悬巷的空间质感，再逐步引出母亲失踪、陆家开发、二十年前雨夜旧案三条线。

## 情绪目标

- 前段：安静、潮湿、隐隐不安。
- 中段：关系对立、证据浮出、旧事压迫。
- 后段：真相逼近、信任动摇、危险落地。

## 爽点设计

爽点不是大喊打脸，而是女主通过细节看穿谎言：

1. 通过遗物摆放判断许婆婆丈夫临终前见过外人。
2. 通过墙灰和钉痕找到第一封信。
3. 通过旧账本夹页发现拆迁名单造假。
4. 在开发听证会上用物证逼陆家承认南悬巷暂缓拆除。

## 感情线节奏

1. 第 1—2 章：立场对立，陆行舟像阻碍。
2. 第 3—4 章：陆行舟掌握她想要的信息，但不完全给。
3. 第 5—6 章：他用行动保护她，江照眠不接受廉价善意。
4. 第 7—8 章：二人短暂合作，旧案线让关系靠近。
5. 第 9—10 章：陆行舟隐瞒关键监控曝光，信任出现裂口。

## 伏笔

- 红漆木箱的钥匙不在江照眠手里。
- 江问雪留下“不信陆家”的信。
- 南悬巷七号墙腹藏信。
- 照相馆半截招牌与旧底片。
- 陆行舟父亲死于二十年前雨季后不久。
- 许婆婆一直不肯搬走，不只是念旧。
- 陆敬尧催促提前拆除七号宅。

## 第一卷前十章功能

前十章完成开局闭环：江照眠接委托 → 进南悬巷 → 遇陆行舟 → 找到母亲来信 → 拆迁压力增强 → 初步合作 → 发现账册异常 → 旧监控存在 → 陆行舟隐瞒 → 江照眠决定公开阻止拆除。
