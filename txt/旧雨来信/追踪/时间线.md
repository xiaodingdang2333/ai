# 时间线

## 第一卷：南悬巷雨夜

| 时间 | 事件 |
|---|---|
| 第 1 日 上午 | 江照眠抵达南悬巷七号旧宅，以遗物整理师身份介入预清场前的旧物整理。 |
| 第 1 日 下午 | 江照眠在七号宅东墙发现异常灰缝，陆行舟第一次正面出场并试图控制现场节奏。 |
| 第 1 日 傍晚 | 江照眠从墙腹取出写着“眠眠”的信封，确认母亲江问雪二十年前留下第一封信。 |
| 第 1 日 夜 | 江照眠回工作室拆信，得知“不要信陆家的任何人”和“去找青岚照相馆”；林澈查到案卷中没有江问雪名字。 |
| 第 1 日 深夜 | 陆行舟到工作室，承认查过江问雪并掌握部分旧监控；许婆婆来电说找到刻“青”字的钥匙。 |
| 第 2 日 凌晨 | 江照眠与陆行舟去后巷见许婆婆，拿到青岚钥匙，并进入青岚照相馆暗房，找到 0712 铁盒和写着“别开灯”的空白相纸。 |
| 第 2 日 上午 | 七号宅提前预清场，江照眠用委托合同和证据状态阻止搬运，陆行舟暂停现场流程但只争取到数小时。 |
| 第 2 日 下午 | 江照眠在七号宅找到青岚照相馆取件单，确认江问雪当年主动去取东西。 |
| 第 2 日 夜 | 相纸显影，出现江问雪抱红漆木箱站在青岚照相馆门口的影像，角落出现疑似陆怀川的旧表；许婆婆住处被翻，账册失窃，只留下写有“怀川”的残页。 |
| 第 3 日 凌晨 | 江照眠扫描账册残页，发现“补偿”“转证”等痕迹；红漆木箱夹层打开，出现七号宅结构图和“下室”标记。 |
| 第 3 日 凌晨 | 江照眠、陆行舟、林澈查补偿名单，发现七号宅、青岚照相馆、周记钟表铺权属被异常替换；陆敬尧派人送和解建议和红漆木屑施压。 |
| 第 3 日 深夜 | 三人进入七号宅下室，发现文件箱被提前搬空、江问雪纽扣和“眠眠，别怕”刻字；撤离时陆行舟口袋里的“南悬巷 0712”U盘暴露。 |
| 第 4 日 清晨 | 江照眠读取旧监控 A/C 段，看到江问雪和陆怀川同入青岚照相馆，关键 B 段缺失；她将证据包发送给媒体和律师，暂缓七号宅清场。 |
| 第 4 日 上午 | 媒体进场后，陆氏用“私人情感”“个别人士”话术引导舆论反扑；陆行舟决定回陆氏调内部审批链。 |
| 第 4 日 下午 | 江照眠收到周记钟表铺旧照片和周姓男子来电，得知南悬巷的表都停在七月十二晚上十点十七分。 |
