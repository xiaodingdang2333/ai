# 卷纲：第一卷 豪门替身新娘

## 大纲四检

### 1. 本卷交付什么情绪？什么剧情模式能可靠交付？

本卷交付“当众受辱后立刻反杀”的爽感。采用女配觉醒 + 豪门退婚 + 白莲翻车 + 追悔火葬场模式。

### 2. 本卷核心冲突是什么？

傅家和林晚晚想让姜照继续当替身、背锅、输血。姜照要退婚、清账、夺权，并证明自己不是任何人的剧情垫脚石。

### 3. 卷节奏如何安排？

- 起：婚礼羞辱，女主当场掀桌。
- 承：傅家和姜家联合施压，林晚晚装病卖惨。
- 转：姜照抛出资金证据和病历证据，舆论反转。
- 合：傅家资金链断裂，傅沉舟追悔，林晚晚被反噬，姜照夺回气运离开。

### 4. 本卷伏笔如何处理？

新埋伏笔：系统 009 的惩罚失效、姜照看见气运流向、林晚晚的病历异常、傅家账目亏空、姜父暗中转移姜照股份。

本卷回收：婚礼羞辱真相、林晚晚假病、傅家靠姜家续命、原身死亡原因、第一块气运碎片。

## 主要人物弧线

### 姜照

被逼下跪的替身未婚妻 → 当场退婚清账 → 掌控姜氏资产 → 夺回气运碎片。

### 傅沉舟

高高在上的豪门继承人 → 被撤资后愤怒反扑 → 发现姜照才是傅家唯一生路 → 追悔求复合失败。

### 林晚晚

柔弱白月光 → 假病受害者人设 → 病历和转账曝光 → 失去傅沉舟和主角光环。

### 姜家父母

要求姜照忍让 → 发现女儿脱离控制 → 试图用亲情绑架 → 股份问题暴露后被反制。

## 爽点节奏

| 阶段 | 爽点 |
|---|---|
| 1—3 章 | 婚礼现场摘戒、退婚、砸出三十七亿欠款 |
| 4—6 章 | 傅家施压失败，姜照冻结资金 |
| 7—10 章 | 林晚晚假病露出破绽，姜照第一次公开证据 |
| 11—15 章 | 傅氏股价下跌，傅沉舟开始慌 |
| 16—20 章 | 姜家父母偏心翻车，姜照夺回股份 |
| 21—25 章 | 林晚晚彻底翻车，傅沉舟跪求复合，姜照抽离世界 |

## 反转设计

1. 读者以为姜照只是退婚，实际她已经控制傅家资金命脉。
2. 傅沉舟以为林晚晚病重，实际病历造假。
3. 姜家以为姜照离不开家族，实际姜氏核心股份早在原身名下。
4. 系统以为可以惩罚姜照，实际惩罚能量被她反向吸收。
5. 林晚晚以为自己是女主，实际她也是被气运机制喂大的容器。
